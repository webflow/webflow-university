Open onboarding stages from at-a-glance links

On /pro/onboarding, a glance-card hash opens that stage accordion and closes the other stages, including when the URL is loaded with the hash. The scroll waits until the accordion height animation finishes, so the stage is not measured while a section above it is still collapsing. The link button on each card copies the stage URL and briefly shows a checkmark.
